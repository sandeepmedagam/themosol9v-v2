# One Venture Studio

Responsive One Venture Studio homepage built with Next.js App Router, React, and TypeScript. `app/reference.css` preserves the supplied 9,291-line stylesheet, `app/tokens.css` maps its typography and color tokens to the application, and `app/globals.css` contains homepage-specific styles.

## Run locally

1. Use Node.js 20.9 or newer.
2. Install packages with `npm install`.
3. Optionally set `NEXT_PUBLIC_BOOKING_URL` to override the booking link.
4. Start the development server with `npm run dev` and open `http://localhost:3000`.

The booking URL defaults to the One Venture Studio calendar link.
